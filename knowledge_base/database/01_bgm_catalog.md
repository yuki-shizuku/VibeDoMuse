# Batch 1: Galgame BGM Catalog

> **Category**: `galgame_bgm`
> **Total Pieces**: 44
> **Format**: JSON only (no WAV conversion)
> **Duration**: ~30 seconds each
> **Purpose**: Melody-driven Galgame background music for AI training

---

## Overview

This batch contains 44 pieces of melody-driven Galgame BGM. Each piece is designed around a specific mood or scene, using varied instruments and melodic patterns. The music is generated using `generate_bgm.py` and stored as JSON source files.

### Generation Tools

- **Script**: `bgm/generate_bgm.py`
- **Engine**: DoMuse.exe (JSON to MIDI)
- **SoundFont**: 32MbGMStereo.sf2 (General MIDI)
- **Structure**: Single-track or dual-track, varied instruments

### Design Principles

- Melody-driven composition (scale-based melody generation)
- Key signatures: C, G, D, F, Am, Em
- Tempo range: 70-130 BPM
- Instruments: Acoustic Grand Piano, Music Box, Violin, Strings, Guitar

## Technical Notes

### Composition Method

- **Melody**: Scale-based generation using pentatonic and diatonic scales
- **Accompaniment**: Simple chord arpeggios and block chords
- **Structure**: 8-16 bar phrases, repeated with variation
- **Duration**: ~30 seconds at specified BPM

### File Locations

| Item | Path |
|------|------|
| JSON files | `bgm/json/*.json` |
| Generator script | `bgm/generate_bgm.py` |
| Documentation | `bgm/DATABASE_DOCUMENTATION.md` |

### Regeneration
