## Overview

This document catalogs all chord progressions used across the Do Muse project. The progressions are organized by batch and key signature, with Roman numeral analysis for easy transposition.

**Key signature**: The key column indicates the tonal center. The chords are actual pitches used in the generation. Roman numerals show the functional relationship and can be used to transpose to any key.

## Batch 2: Accompaniment (Harmony-driven)

### Group 1: Pop Standard (I-V-vi-IV)

```
Key: C
C → G → Am → F
I  → V → vi → IV
```

The most popular progression in modern pop music. Used in countless J-pop and anime songs.

### Group 2: Komuro Progression (vi-IV-V-I)

```
Key: C
Am → F → G → C
vi → IV → V → I
```

Named after Tetsuya Komuro, this is a hallmark of 1990s J-pop and still widely used in Galgame music.

### Group 3: 4516 Progression (IV-V-iii-vi)

```
Key: C
F → G → Em → Am
IV → V → iii → vi
```

A Japanese anime/game standard with a descending bass feel.

### Group 4: Chorus Turnaround (I-vi-IV-V)

```
Key: C
C → Am → F → G
I → vi → IV → V
```

The classic 50s progression, also known as "doo-wop" changes. Bright and satisfying.

### Group 5: II-V-I Jazz (ii7-V7-Imaj7)

```
Key: C
Dm7 → G7 → Cmaj7 → Cmaj7
ii7 → V7 → Imaj7 → Imaj7
```

The fundamental jazz cadence. Extended chords (7ths) add sophistication.

### Group 6: Canon Progression (I-V-vi-iii-IV-I-IV-V)

```
Key: C
C → G → Am → Em → F → C → F → G
I → V → vi → iii → IV → I → IV → V
```

The Pachelbel Canon harmonic sequence. 8 chords, epic and emotional.

### Group 7: Minor Cycle (vi-ii-V-I)

```
Key: C
Am → Dm → G → C
vi → ii → V → I
```

A minor-mode cycle that resolves to the tonic. Melancholic but hopeful.

### Group 8: Basic Blues (I-IV-V-I)

```
Key: C
C → F → G → C
I → IV → V → I
```

The simplest and most universal progression. Rock and blues foundation.

### Group 9: Extended Harmony (iii-vi-ii7-V7)

```
Key: C
Em → Am → Dm7 → G7
iii → vi → ii7 → V7
```

All chords are color tones. Creates a sophisticated, wandering feel.

### Group 10: Mixed Jazz (Imaj7-vi7-IVmaj7-V7)

```
Key: C
Cmaj7 → Am7 → Fmaj7 → G7
Imaj7 → vi7 → IVmaj7 → V7
```

All extended chords. Lush, rich, jazz-influenced harmonic texture.

## Batch 3: Multi-key v3

### Group 1: C Major — Cheerful Pop (I-iii-IV-V)

```
Key: C
C → Em → F → G
I → iii → IV → V
```

Mediant substitution (iii instead of vi) gives a brighter, more open feel.

### Group 2: G Major — Warm Standard (I-IV-ii-V)

```
Key: G
G → C → Am → D
I → IV → ii → V
```

Supertonic (ii) instead of vi in the subdominant position. Warm and standard.

### Group 3: D Major — Uplifting (I-vi-IV-V)

```
Key: D
D → Bm → G → A
I → vi → IV → V
```

The classic pop formula in bright D major. Bm (vi) adds emotional depth.

### Group 4: F Major — Tender (I-V-ii-IV)

```
Key: F
F → C → Dm → Bb
I → V → ii → IV
```

Subdominant expansion with Bb (IV) at the end. Tender and warm.

### Group 5: Bb Major — Smart Jazz (I-vi-IV-V)

```
Key: Bb
Bb → Gm → Eb → F
I → vi → IV → V
```

Same popular formula but in Bb major, giving a jazzier, richer tonal color.

### Group 6: A Major — Bright (I-IV-vi-V)

```
Key: A
A → D → F#m → E
I → IV → vi → V
```

Bright open strings resonance. F#m (vi) creates a natural emotional lift.

### Group 7: Eb Major — Rich (I-vi-IV-V)

```
Key: Eb
Eb → Cm → Ab → Bb
I → vi → IV → V
```

Three flats create a dark, rich tonal palette. Cm (vi) is particularly expressive.

### Group 8: A Minor — Melancholic (i-iv-V7-i)

```
Key: Am
Am → Dm → E7 → Am
i → iv → V7 → i
```

Harmonic minor resolution with E7 (V7). The major V creates strong tension.

### Group 9: E Minor — Thoughtful (i-VI-III-VII)

```
Key: Em
Em → C → G → D
i → VI → III → VII
```

Modal progression with a Dorian flavor. No leading tone, floating and thoughtful.

### Group 10: D Minor — Dramatic (i-iv-V7-III)

```
Key: Dm
Dm → Gm → C7 → F
i → iv → V7 → III
```

Minor with a surprising Picardy third (F major at the end). Dramatic and cinematic.
